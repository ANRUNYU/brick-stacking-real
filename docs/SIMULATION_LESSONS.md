# 仿真经验的适用边界

来源：先前 Rabokit 项目的日志与讨论，标签 `simulation_example`。不作为真机接口或精度证据，没有导入原控制代码。

- SDK 返回成功与画面/反馈完成必须区分；真机仍需新鲜反馈、视觉复检和独立精度测量。
- 不同应用 namespace 会导致观察和控制对象错配；真机需独立设备身份与流来源。
- 小幅动作可能肉眼不明显；试验记录目标、实测变化和噪声，而非仅靠观看。
- O6 仿真曾出现开手不稳定、超时和停止接口能力不符；不能移植其手势、通道映射或把退出进程当作物理停车。
- 同色相邻轮廓可合并，按约 50 mm 长度推断只是模型假设；没有接缝/多视角证据时保留歧义。
- 必须使用图像时刻的 TF 与一致时钟域，不能混用 latest TF 或跨重置时刻的观测。
- 不把可见面三维点当作物体中心，不把物体中心直接当作腕部目标。

独立真机工程从模型、接口、记录与测试重新建立上述约束；仿真通过不转换为真机通过。
