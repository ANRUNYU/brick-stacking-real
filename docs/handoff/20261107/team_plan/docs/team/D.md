# D个人开发计划：灵巧手与任务流程

负责人：D；阶段一10点，阶段二10点。默认配对审查见总体计划。

## 1. 代码与职责
归属：src/brick_stacking/hand/、scene/、task/、execution/；tests/task/；config/hand/

可独立开工：先做O6只读、MockHand及Mock单块FSM；第二阶段先用预置观测跑十块流程。公共契约只做薄骨架。

边界：不代写A/B/C的实现、Mock和测试，不重新计算TF/碰撞，不独自背负所有集成修复。

主要交接：B：观测和视觉证据；C：世界目标/轨迹；A：执行状态/停止能力。

## 2. 第1阶段任务

### D1-01 公共契约落库与离线入口（1点）

- 输入：全员确认的CONTRACTS.md。
- 工作与交付：contracts类型骨架、CLI dry-run、接口样例。
- 验收：全员签认M0；仅薄骨架，不代写A/B/C的Mock或工具。
- 依赖与替代路径：无实现依赖；C审几何、A/B审设备字段。

### D1-02 O6绑定与状态适配（2点）

- 输入：O6 SN/CAN审计、已安装SDK。
- 工作与交付：HandAdapter、MockHand、raw/percent显式类型。
- 验收：选侧一致；只读无动作副作用；不假设有触觉或可靠停止能力。
- 依赖与替代路径：M0；可独立于机械臂。

### D1-03 抓握预设与状态判据（3点）

- 输入：所选手、实物木块、现场受控测试。
- 工作与交付：张开/抓握/释放预设、抓握报告。
- 验收：先支撑/台架评估；预设记录单位/速度/版本；不凭命令返回推断持物。
- 依赖与替代路径：离线独立；真机与A预约同一整机。

### D1-04 单块FSM与SafetyGate（2点）

- 输入：A/B/C Mock、契约样例。
- 工作与交付：PickPlaceFSM、门控、超时/重试/事件日志。
- 验收：正常与失败路径离线可复现；过期反馈/校准无效/未知许可不执行。
- 依赖与替代路径：M0后独立；各模块提供自有Mock。

### D1-05 单块真实闭环接入（2点）

- 输入：A执行器、B观测、C路径。
- 工作与交付：M3可配置单块任务与报告。
- 验收：抓起和放稳分别验证；失败/取消有界且不盲目撤退或断使能。
- 依赖与替代路径：M2→M3。

## 3. 第2阶段任务

### D2-01 多积木场景与任务规划（3点）

- 输入：B样例观测、C槽位模型。
- 工作与交付：持久block ID、slot状态、颜色排序和支撑DAG。
- 验收：多个同色实体不混淆；仅支撑verified才排上层；一块/一槽单事务。
- 依赖与替代路径：M3；Mock样例即可并行。

### D2-02 整场FSM与有界恢复（3点）

- 输入：各模块契约与Mock错误场景。
- 工作与交付：完整10块任务、重观察/重试/终止策略。
- 验收：倒塌使相关状态失效；无无限重试；重启重扫，拒绝旧动作重放。
- 依赖与替代路径：M4离线，不等待多层硬件实现。

### D2-03 自主运行和统计入口（2点）

- 输入：M5链路、规则配置。
- 工作与交付：一次合法启动、配置快照、可取消任务、整场报告。
- 验收：运行中不逐步等人工；人工介入单独标记，不计无人成功。
- 依赖与替代路径：M5；完整规则缺项显式标记。

### D2-04 验收组织与手/流程问题修复（2点）

- 输入：M6试验数据、各人模块报告。
- 工作与交付：汇总报告、未闭环问题清单。
- 验收：D只汇总和修自身模块；A/B/C各自承担模块指标与修复。
- 依赖与替代路径：M6。

## 4. 提交与合并

每个任务独立小PR；引用任务ID和对应M点。先提交Mock/录包/只读能力，再在关联任务补真机验收证据。生产者负责样例和Mock，接收者负责调用适配。M2配对联调，M3阶段一验收，M4离线十块流程，M5多层实机，M6整体验收。详见[合并计划](../MERGE_PLAN.md)。

所有实际测量和动作记录source、设备、配置、校准版本及run_id；没有做过的验证明确标待测。点数偏差在合并点调整，不能隐瞒阻塞或以模拟成功宣称真机通过。
