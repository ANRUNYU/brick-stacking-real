# 合并、联调与交接点
M0—M6是两个开发阶段内的合并点。每个点记录相关PR、输入版本、输出版本和验收证据；不以“代码已合并”替代真实设备通过。

|点|参与及提交|合并到主线的内容|验证/放行条件|失败时继续做什么|
|---|---|---|---|---|
|M0 契约与基线|全员；D薄骨架，A/B/C各自样例|契约、任务表、目录归属、设备实测快照、主臂选择记录|全员确认单位/坐标/时间/失败语义；主臂选择可暂待测，真实动作锁关闭|未决设备问题不阻止离线类型/Mock开发|
|M1 四模块最小PR|A/B/C/D分别提交，不强制同日完成|A MockArm/只读；B录包/检测；C几何/规划样例；D MockHand/FSM|每个PR单独满足契约和本模块验证；无默认动作副作用|失败PR独立修复；其他模块用冻结样例继续|
|M2a 运动链|C给轨迹，A执行并反馈；C主持|规划→执行→结果/取消链路|先Mock；真实固定目标前必须身份/限位/零位/TCP/所用坐标链/碰撞/StopPolicy/现场安全门槛通过|C继续离线路径；A专项排障，禁止带未验收腕轴抓放|
|M2b 观测与手/流程链|B给观测/复检，D给手/状态机；B主持|观测→目标选择→Mock执行→手/复检事件|回放成功/失败/遮挡/过期/超时；O6独立验证，不能与运动线私自并行动作|B扩充录包，D扩展Mock错误路径|

|M5 第二阶段实机合并|四人；A协调预约，C负责几何放行|两层受控测试→完整四层|每层复检、持物/支撑证据、碰撞与退路；失败有界；运行状态可追溯|修本模块并从受影响层重新验收，不靠人工扶正算自主成功|
|M6 最终验收合并|各人交模块报告，D只汇总|完整自主入口、冻结配置、测试报告、未解决问题|建议多轮完整运行；无人工成功与辅助测试分开；达到事先冻结的质量门槛|核心未达标则保留未验收，不能以进入截止日宣称完成|

## 逐对合并的具体责任
- A→C：提供Mock和真实JointState样例、硬件限制及执行能力。C验证关节命名/方向/单位；A修反馈或驱动问题。
- C→A：提供带时间轨迹、预期起点、限位与碰撞版本。A先dry-run校验；C修路径和模型，A修执行。
- B→C：提供RGB-D、K/D、尺度、时钟与profile；C提供标定采集请求并校验几何。B修数据/配准，C修变换/标定。
- B→D：提供观测集合与VerificationEvidence；D管理实体ID和事务。B修漏检/误报，D修状态提交/重试。
- D手→C：提供手形、抓握预设及实测物体持握几何；C确定TCP/接近/释放路径。D修预设，C修工具模型。
- C→D：提供LocalizedBlock和PlanResult；D只选择可行计划并检查版本/时效，不绕过C另算轨迹。
- D→A：传计划及permit，订阅执行结果。A拒绝无效命令，D不得忽略拒绝并继续抓握步骤。
- 四人共同：同一场景、同一配置、同一标定版本的端到端回放/实机日志。

## 真实依赖与并行规则
M2a与M2b的软件/录包验证可同时进行；同一实体机器上的动作测试必须串行预约。M3不要求多块分割已经完成；M4不要求新的腕相机精定位已完成。M4离线开发可在等待M3现场窗口时开始，但M5真实动作必须等待M3实际通过。

固定目标若以经测量的机械臂基坐标给出，只校验该动作实际使用的坐标链，不强制等待尚未使用的视觉定位链；接入视觉目标后必须通过头部外参与时间/配准门槛。固定目标仍需真实环境几何、工具标定和完整安全检查。
