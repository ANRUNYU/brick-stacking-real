# 总体计划与工作量
## 1. 目标、范围和现实前提
阶段一完成限定工作区单块自主抓放；阶段二完成单臂自主十块搭建。目标包括识别、选块、抓握、搬运、逐层放置、撤离复检和有界恢复。当前不做双臂协作、三机稠密融合、端到端学习或释放后侧向推挪。腕相机只有在误差分析显示必要时接入当前所选侧，按收益替换低优先级增强，不额外堆给某一人。

主臂尚未选定，不能直接默认左或右。A给两侧已有运动表现和反馈证据，C评估安装/可达性，D核对手状态，全员在M0记录选择。另一侧的停放和保持安全也须确认；“没有控制另一侧”不等于另一侧一定安全。

实测：can0右O6/0x27，can1左O6/0x28，can2左臂61—67，can3右臂51—57；头部335L/CP2L863000KL，左腕Gemini2/AY6M8630086，右腕Gemini2/AY6M86300GH。腕轴低速卡顿、普通用户相机权限、配准/标定、限位/零位、安全停止尚未全部验收。旧手ROS配置与实物不匹配，不直接启动。设备身份以SN和物理路径联合校验，不靠枚举顺序。

只有一页赛规摘录，能确认结构/颜色/允许自主或遥操等；完整时限、评分容差和稳定时长仍待补。50mm漆面木块是团队信息，需实测。未知参数保持null。本文验收样本量属于研发建议，不是赛规。

## 2. 工作量安排
|人|模块主责|阶段一|阶段二|合计|配对审查|
|---|---|---:|---:|---:|---|
|A|机械臂通信、轨迹执行与控制异常|10点|10点|20点|C|
|B|相机、感知与视觉证据|10点|10点|20点|D|
|C|几何、标定、抓放规划及碰撞检查|10点|10点|20点|A|
|D|O6、任务状态机及执行前门控|10点|10点|20点|B|

点数是相对复杂度和风险，不是天数、工时承诺或绩效。每人约预留自己容量的20%用于联调/审查/问题修复，点数已含这些工作，不再把公共集成全部加给D。每个合并点后依据实耗重新估算。C的几何/碰撞与A的腕轴风险可能显著超预期，不能用纸面点数宣称实际绝对均衡。

A1-03先做有界诊断；一次约定的排障窗口结束仍无确定结论时，C配合分析，不继续无期限单人调参。相应延后C的路径优化或腕视觉增强，调整任务归属和点数。D的O6/FSM过载时，把已有模块的测试数据生成交还A/B/C，不能由D替所有人写Mock和测试。

## 3. 两阶段内的执行顺序
阶段一：
- M0：公共契约、样例、主臂选择与文件归属确认。
- M1：四个模块各自的Mock/录包/只读最小实现可合并；不需要等四个人同时完成。
- M2：A+C运动链与B+D观测/手/流程链分开联调；真实运动前另过安全门槛。
- M3：固定位置抓放先通过，再打通视觉定位单块闭环，形成阶段一验收报告。

阶段二：
- M4：多块观测、多层规划、十块FSM、连续执行的离线闭环。
- M5：真实多层搭建，先两层再完整十块，逐步验证支撑与精度。
- M6：多轮完整自主验收；四人分别修复各自模块，D汇总。

## 4. 最少等待的工作方式
A使用样例轨迹和模拟反馈；B使用录包或独立采集；C使用样例JointState/观测和合成几何；D使用各模块提供的Mock和预置错误场景。因此M0后都能开始，阶段二的离线任务也可在阶段一的真机预约间隙推进。

真实标定确实依赖A的新鲜状态和B的相机输出，真实抓放依赖四条链路；这些物理依赖不能靠Mock消除。先用离线替代物把软件做完，再集中预约实机补依赖。没有真实数据只能标记离线通过，不能提前宣称真机完成。

全机器人同一时间只有一名现场动作负责人。即使手、臂CAN不同，安装在同一实体上的真实动作也不能各人私自同时测试。相机开流也要登记所有者，避免进程抢占。预约表记录目的、设备、操作者、恢复状态与日志位置。离线和录包任务不占动作预约。

## 5. 交付与追踪
每个任务交：代码/配置、说明、输入输出样例、适当的验证记录及已知限制。任务状态为TODO/IN_PROGRESS/REVIEW/WAITING_FOR_MEASUREMENT/DONE；有外部阻塞写具体条件并继续不依赖该条件的任务。

每个Issue引用任务ID、验收条件、所属合并点和依赖。验证必须注明mock/recorded/real、设备SN、配置/标定版本、是否人工介入。代码合并不等于硬件验收；离线PR可以先合并，真实执行开关保持关闭。
