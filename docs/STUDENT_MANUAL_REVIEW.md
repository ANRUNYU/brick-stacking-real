检查日期：2026-11-06。来源：工作区《灵巧操作具身智能实践课---学生手册.pdf》，91 页；提取文本并查看了安装截图页及关键章节。

## 可用内容

- 第 7 页起：Ubuntu 24.04 + ROS 2 Jazzy 环境配置。
- 第 33–34 页：进程、网络与 IP 信息查看。
- 第 38–63 页：ROS 2 节点/话题/消息/服务/Action/工作空间，以 turtlesim 为教学对象。
- 第 64–91 页：VS Code、ament_python、rclpy Publisher/Subscriber 和小乌龟控制练习。

这些适用于 Linux 环境、ROS 基础及后续 Python 节点组织，不是该双臂机器人的设备接入手册。没有找到机器人专属 IP/SSH 用户名、USB 网络模式、实际 P7/O6 驱动启动配置、CAN 身份或标定信息。教学中的命令不是用户授权执行的操作；本轮没有修改系统源、启动驱动、发送话题命令或执行电机动作。

## 本机只读检查结果

Windows OpenSSH 客户端存在。当前网卡清单仅 WLAN 处于连接状态；物理以太网断开，未发现枚举为 USB/RNDIS/CDC 网卡的接口，也没有 Ports 类串口设备。存在通用 USB Composite Device，不能凭名称判断是机器人主机。

因此尚不能确认 USB 已形成可用的网络或串口通道，也不能断言线路损坏。不扫描校园网络、不猜测机器人地址、不将本机 Wi-Fi 地址当作机器人地址。

## 下一步

确认线缆两端接口、机器人主机是否开机；获取该主机实际 IP 和 SSH 用户名。可以在机器人主机本地终端只读执行 `hostname -I`、`whoami`、`cat /etc/os-release`、`printenv ROS_DISTRO`。若 USB 不支持网络，可使用团队确认的有线/Wi-Fi 网络路径。

Windows 可通过 SSH 远程运行机器人 Linux 上的程序，本机无需安装 ROS 2。首次连接后先核实主机身份、OS/ROS、已有设备和节点；不实例化存在初始化副作用的 P7 SDK。运动测试仍需验证实际驱动/限位/停止能力和现场测试条件。
