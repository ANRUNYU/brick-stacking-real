# 里程碑与验收

| 阶段 | 当前交付/下一项 | 验收证据 |
|---|---|---|
| M0 离线基础 | 本轮目录、接口、来源固定版本、URDF 静态检查 | 单测/审计文档；实际设备身份仍待确认 |
| M1a 合成原型 | 四色候选、无效深度、同色紧贴拒绝强拆、回放 | 固定合成预期；本轮可验收的软件范围 |
| M1b 真实视觉 | 待增加真实样本、标注、桌面分离与可靠实例分割/追踪 | 固定测试集，误分/漏分/歧义率与深度有效率；不以单张截图验收 |
| M2 坐标 | 数学基础已有；手眼/TCP 流程与真实数据待补 | 多位置/高度独立物理误差 P50/P95，不只重投影误差 |
| M3 单臂抓放 | 未开发硬件执行 | 批量随机位置抓放；新鲜反馈、视觉确认、失败分类 |
| M4–M6 | 多层/腕部修正/交接/全自主后续开发 | 依设计 v0.2 分阶段统计，人工介入单独计数 |

v0.2 新增十块单臂 Mock 场景事务与交接纯逻辑测试，不将其计入 M3–M6 真机完成。Windows 本地完整套件已通过 53 项；Ubuntu/Jazzy 目标已确认，Linux/CI 执行仍待进行。部署见 DEPLOYMENT.md，框架边界见 FRAMEWORK.md。

离线测试覆盖：变换方向与逆变换、坏旋转、动态 TF 过期/时钟域、米制反投影、无效深度、颜色 hue wrap、紧贴歧义、平面异常点、unknown 高度格、回放、配置拒绝真机、Mock、URDF 缺项不编造、记录重名和错误报告。

默认 pytest 排除 hardware/motion；本版没有硬件测试文件与真实连接代码。首轮不会为目录完整而生成无法运行的 ROS 节点。
