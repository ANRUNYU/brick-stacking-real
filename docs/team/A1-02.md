# A1-02 控制适配与离线执行器（M1）

`brick_stacking.arm.adapter` 提供 `ArmAdapter` 协议、`MockArm` 和 `replay_execution()`。执行器使用 M0 的 `Trajectory`、`Permit`、`ArmState` 和 `ExecutionResult`，支持以 JSON 保存回放结果。

```python
from brick_stacking.arm.adapter import JOINT_NAMES, replay_execution, trajectory_hash

trajectory = {"joint_names": JOINT_NAMES, "points": (
    {"time_from_start_s": 0.0, "q_rad": (0.0,) * 7},
    {"time_from_start_s": 1.0, "q_rad": (0.1,) * 7},
    {"time_from_start_s": 2.0, "q_rad": (0.2,) * 7},
)}
permit = {
    "device_id": "mock-arm",
    "config_hash": "mock-config",
    "calibration_hash": "mock-calibration",
    "scene_version": "mock-scene",
    "trajectory_hash": trajectory_hash(trajectory),
    "valid_until_host_monotonic_s": 4.0,
}
trace = replay_execution(trajectory, permit, (0.0,) * 7, (
    (0.0, "step"), (1.0, "step"), (1.5, "cancel"), (2.0, "step"),
))
assert trace[-1]["status"] == "CANCELLED"
assert trace[-1]["feedback"]["q_rad"] == (0.1,) * 7
```

回放的时钟从 `0.0` 秒开始，同一时刻的操作按脚本顺序处理。直接使用 `MockArm` 时，`execute_trajectory()` 校验后返回命令 ID，由调用方通过 `step()` 应用已到时的轨迹点。`get_execution_result()` 保留当前命令的结果，回放列表可保留各步骤快照。回放中的样本、会话和命令 ID 每次重新生成。

执行器检查 J1–J7 顺序、七轴有限弧度值、严格递增的相对时间、许可绑定和截止时间。许可和可选的轨迹截止时间取较早值，截止时刻视为已过期。运行中到期或取消后，后续轨迹点不会改变 Mock 关节状态。`SUCCEEDED` 表示已应用最后一个模拟目标并取得 Mock 反馈。真机反馈、限位、碰撞校验及停止行为属于后续任务。

离线验收运行 `python -m pytest tests/arm`。
