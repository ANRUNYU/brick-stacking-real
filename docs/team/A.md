# A个人开发计划：机械臂控制

负责人：A；阶段一10点，阶段二10点。默认配对审查见总体计划。

## 1. 代码与职责
归属：hardware/中的机械臂适配及对应Mock/测试/臂配置；A拥有设备执行实现。

可独立开工：首选独立做只读绑定、Mock执行与轨迹校验；腕轴排障有界，不把其他人的离线开发一起卡住。

边界：不负责O6预设、相机识别、全路径碰撞规划或整场任务排序。

主要交接：C：轨迹/关节单位；D：permit与结果；B：仅需要共同时序约定。

## 2. 第1阶段任务

### A1-01 设备绑定与只读状态（1点）

- 输入：审计映射和现有SDK。
- 工作与交付：arm/state，关节名、rad、时间戳及有效位。
- 验收：错接口/错ID拒绝绑定；读取不触发使能/Rest/模式写入。
- 依赖与替代路径：M0；无其他模块实现依赖。

### A1-02 控制适配与离线执行器（2点）

- 输入：契约轨迹和Mock反馈。
- 工作与交付：ArmAdapter、MockArm及执行回放。
- 验收：轨迹关节顺序、时序、非有限值、过期与取消检查通过。
- 依赖与替代路径：M0；使用轨迹样例。

### A1-03 所选臂腕关节与停止行为专项（3点）

- 输入：实际腕轴、日志、匹配固件资料。
- 工作与交付：跟踪报告、限速依据、逐设备StopPolicy证据。
- 验收：先诊断后受控测试；无法确认安全/跟踪时明确BLOCKED，不盲调增益。
- 依赖与替代路径：离线独立；真实动作前需现场安排与匹配资料。

### A1-04 轨迹执行及结果反馈（2点）

- 输入：C提供的轨迹样例，随后接真实规划。
- 工作与交付：execute/cancel/status/result接口。
- 验收：只有新鲜实测到位才SUCCEEDED；拒绝过期许可和轨迹。
- 依赖与替代路径：先Mock；真机依赖M2运动链。

### A1-05 单块闭环接入与执行验收（2点）

- 输入：C规划、D流程。
- 工作与交付：固定与视觉抓放的执行日志。
- 验收：接入M3；定位误差与执行误差分开报告；无遗留命令队列。
- 依赖与替代路径：M2→M3。

## 3. 第2阶段任务

### A2-01 多层连续执行与时间统计（3点）

- 输入：M3接口、多层轨迹样例。
- 工作与交付：多高度执行、进度/耗时统计。
- 验收：多段连续执行仍检查新鲜度/限位；取消后不继续执行后续段。
- 依赖与替代路径：可先回放；实机依赖M5。

### A2-02 控制异常与恢复入口（3点）

- 输入：Mock故障用例、StopPolicy。
- 工作与交付：超时/过期/断连/进程重启处理。
- 验收：Mock注入故障通过；真实故障实验另行评估；重启不重放旧命令。
- 依赖与替代路径：M3；不等待视觉增强。

### A2-03 全流程控制稳定性（2点）

- 输入：M5自主流程。
- 工作与交付：控制频率、抖动、反馈延迟与温升报告。
- 验收：如实记录异常与停止；不以平均值掩盖最大间隔。
- 依赖与替代路径：M5→M6。

### A2-04 联合验收与控制问题修复（2点）

- 输入：M6运行清单。
- 工作与交付：控制模块验收报告和修复PR。
- 验收：控制问题由A闭环；协助C检查路径执行一致性。
- 依赖与替代路径：M6。

## 4. 提交与合并

每个任务独立小PR；引用任务ID和对应M点。先提交Mock/录包/只读能力，再在关联任务补真机验收证据。生产者负责样例和Mock，接收者负责调用适配。M2配对联调，M3阶段一验收，M4离线十块流程，M5多层实机，M6整体验收。详见[合并计划](../MERGE_PLAN.md)。

所有实际测量和动作记录source、设备、配置、校准版本及run_id；没有做过的验证明确标待测。点数偏差在合并点调整，不能隐瞒阻塞或以模拟成功宣称真机通过。
