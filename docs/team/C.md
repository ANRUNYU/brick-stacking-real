# C个人开发计划：标定与规划

负责人：C；阶段一10点，阶段二10点。默认配对审查见总体计划。

## 1. 代码与职责
归属：localization/、calibration/、标定工具和planning/中的运动规划；复用现有几何模型。

可独立开工：先用合成/样例几何开发；真实采样依赖A/B，提前写好采集接口及独立误差验证工具。

边界：不直接发CAN，不维护持久任务场景，不把IK通过当碰撞通过。

主要交接：A：状态和轨迹执行；B：配准图与标定数据；D：抓握几何及场景版本。

## 2. 第1阶段任务

### C1-01 坐标约定与离线几何（1点）

- 输入：契约、URDF候选、样例关节状态。
- 工作与交付：transform/FK接口及单位方向测试。
- 验收：T_A_B方向、m/rad、四元数顺序有独立可计算用例；模型版本记录。
- 依赖与替代路径：M0；独立于真实感知。

### C1-02 标定工具与采样方案（2点）

- 输入：RecordedCamera、合成标定数据。
- 工作与交付：标定采集/求解/报告工具。
- 验收：拒绝缺失外参、错误分辨率、退化样本；不伪造实际矩阵。
- 依赖与替代路径：可离线先行；真实采样需A/B数据。

### C1-03 所选臂安装/头部/TCP标定（3点）

- 输入：B头部观测、A新鲜状态、现场量测。
- 工作与交付：带版本外参、TCP、多点物理误差报告。
- 验收：训练采样与独立验证点分离；测工作区不同位置/高度的mm误差。
- 依赖与替代路径：真实依赖M1；离线工具不等待。

### C1-04 单块抓放路径与几何检查（2点）

- 输入：已知目标或模拟观测、环境几何。
- 工作与交付：PlanningModule、接近/抬升/放置/撤退轨迹。
- 验收：IK失败、限位、桌面/手掌/相机/持物碰撞拒绝；许可独立生成。
- 依赖与替代路径：Mock可独立；真实执行需要标定通过。

### C1-05 坐标—路径—执行联合验证（2点）

- 输入：A反馈、B观测、D预设几何。
- 工作与交付：M3路径及误差分解报告。
- 验收：固定点先验证，再视觉随机点；规划成功不直接表示抓放成功。
- 依赖与替代路径：M2→M3。

## 3. 第2阶段任务

### C2-01 多层槽位几何与释放规划（3点）

- 输入：实测积木尺寸、table坐标、D支撑DAG。
- 工作与交付：参数化槽位/接触面与多层路径。
- 验收：层高/间隙可配置；不硬编码假尺寸；支撑关系和邻块碰撞一致。
- 依赖与替代路径：M3；可用合成结构独立开发。

### C2-02 持物偏移与放置精度（3点）

- 输入：D抓握预设、B物体观测、误差数据。
- 工作与交付：T_tcp_block估计、释放前有限修正。
- 验收：误差预算驱动改进；需要腕机时补手眼/时间对齐，未通过则不启用。
- 依赖与替代路径：离线先行；实机改进依据M3误差。

### C2-03 遮挡/可达性与路径改进（2点）

- 输入：目标集合、失败场景样例。
- 工作与交付：可达性结果、接近候选、路径成本。
- 验收：失败有原因；不越过碰撞硬约束；当前仅单臂。
- 依赖与替代路径：M4离线；M5真机。

### C2-04 整场规划与标定复验（2点）

- 输入：M5/M6数据、独立测点。
- 工作与交付：精度与路径失败率报告。
- 验收：变更TCP/夹持/相机安装后相关标定失效并复验。
- 依赖与替代路径：M6。

## 4. 提交与合并

每个任务独立小PR；引用任务ID和对应M点。先提交Mock/录包/只读能力，再在关联任务补真机验收证据。生产者负责样例和Mock，接收者负责调用适配。M2配对联调，M3阶段一验收，M4离线十块流程，M5多层实机，M6整体验收。详见[合并计划](../MERGE_PLAN.md)。

所有实际测量和动作记录source、设备、配置、校准版本及run_id；没有做过的验证明确标待测。点数偏差在合并点调整，不能隐瞒阻塞或以模拟成功宣称真机通过。
