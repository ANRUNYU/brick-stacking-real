# D1-01 公共契约与离线入口

M0 审阅稿，契约版本 0.1。规范见 [CONTRACTS.md](CONTRACTS.md)。

## 离线运行

在仓库根目录执行以下 PowerShell 命令。仓库支持 Python 3.11 或更新版本，契约预览入口本身无需第三方依赖。

```powershell
$env:PYTHONPATH = (Resolve-Path ./src).Path
python -m brick_stacking.contracts --dry-run
```

入口输出 JSON，包含契约版本、`motion_enabled: false` 和一个空场景。省略 `--dry-run` 或传入未知参数会以非零状态退出。入口仅加载标准库和契约类型，无设备配置、SDK 或真实执行路径。

## 接口样例

以下是 D 负责的场景接口示例。字典键分别是持久积木 ID 和槽位 ID。观测引用来自生产者，只有收到并接受复检证据后，任务逻辑才可提交槽位成功。此例中的引用仅用来说明字段关系。

```python
from brick_stacking.contracts import SceneSnapshot
from brick_stacking.models.scene_state import SlotState

scene: SceneSnapshot = {
    "scene_version": "example-1",
    "blocks_by_id": {
        "block-001": {"holder_id": None, "observation_refs": ("obs-001",)},
    },
    "slots_by_id": {
        "base-01": {
            "state": SlotState.EMPTY,
            "block_id": None,
            "support_slot_ids": (),
            "evidence_refs": (),
        },
    },
}
```

类型骨架保留未知值。例如 `dq_rad_s=None` 表示未知速度，`depth_registered_to_rgb=None` 表示配准状态未知，`feedback_confirmed=False` 表示停止反馈尚未确认。手部预设的位置和速度各带单位标签。七轴顺序、数值范围、样本新鲜度及动作许可检查由后续任务实现。所有 `host_monotonic_s` 字段只能在同一主机单调时钟域中比较。

## 合入与签认

契约类型用于 M0 模块间交换。槽位状态复用现有 `SlotState`。`models.scene_state.SceneSnapshot` 表示一次观测，新契约中的 `SceneSnapshot` 表示带版本和槽位证据的任务视图。`CameraFrame` 仍由现有感知流程消费，`RGBDObservation` 为交换层保留原始尺度、数据引用和未知配准状态。现有 Mock 流程继续使用其原有模型和协议，契约预览可单独运行。

C 核对几何字段，A/B 核对设备字段。各生产者提供索引里的样例后，A/B/C/D 共同确认单位、坐标、时钟和失败语义，完成 M0 冻结。
