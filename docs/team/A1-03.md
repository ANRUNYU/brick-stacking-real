## 限速依据

生产速度、加速度、跟踪误差及超时阈值均待确定。审计中的 SDK 默认编解码量程和 200 ms 心跳只提供代码行为线索。实际驱动器参数、保持表现及低速跟踪上限仍待测。

选侧后先关联驱动器身份、固件版本和匹配参数资料，核对量程、零位、软硬限位及负载条件。现场评估后，在受控窗口内分别记录 J6/J7 的双向低速跟踪、静止保持和停止。每轮留存 run ID、设备身份、固件、commit、配置与校准 hash、负载、目标发送与反馈时间、原始帧索引和终止原因。误差、采样时序、异常中止和限速判据须在现场测试前冻结。安全或跟踪结论仍未知时保留 `BLOCKED`。
