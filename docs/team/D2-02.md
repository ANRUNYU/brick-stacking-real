# D2-02 整场 Mock FSM 与有界恢复

对应 M4，依赖 [D2-01 的场景事务与支撑 DAG](D2-01.md)。现有十块入口执行红 4、黄 3、蓝 2、绿 1 的离线任务。事件记录包含观察 ID、会话 epoch、动作序号、重观察原因及失效槽位。

## 运行与恢复规则

- 每次启动先在新 epoch 重扫。使用新建的执行器和场景管理器，按当前帧位置、颜色和支撑重新确认已放置的积木。重扫发现持物、未知位置、占位歧义或未验证支撑时安全退出。
- 每个模拟动作绑定 epoch、递增序号和槽位。Mock 执行端拒绝旧会话、重复序号及乱序动作。旧观察也须通过当前 epoch、时钟、时间戳和观测 ID 检查。日志用于审计，重启以新的观测为输入。
- 选取失败、抓放复检遮挡和已提交槽位暂不可见时，每处最多重观察 `max_reobservations` 次，默认 2。重观察期间不下发动作。抓取重试仅在新证据确认积木仍在供料区且手为空时进行，每块最多 `max_grasp_retries` 次。
- 已验证槽位出现位置偏差或失去观测证据且耗尽预算时，将相关槽位和支撑后代降为 `UNVERIFIED`，保留其积木归属并终止。失败后保持当前模拟持物状态，不自动释放或撤退。
