按 2026-11-07 硬件审计绑定左臂 `can2`（61–67）或右臂 `can3`（51–57）。绑定检查接口名、udev `ID_PATH` 和七个电机的协议应答。Linux 上安装 `pip install '.[arm-readonly]'`，使用已配置的 SocketCAN 接口显式读取一次状态。

```python
from brick_stacking.arm.state import ArmStateReader

with ArmStateReader.open("left", "can2") as arm:
    sample = arm.read_state()
```
