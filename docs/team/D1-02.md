# D1-02 O6 绑定与只读状态适配

D1-02 对应 M1，依赖 D1-01 的 M0 契约。绑定记录来自 2026-11-07 交付包的 `interface_audit/HARDWARE_INTERFACES.md` 第 4 节和 `evidence/can.json`。

|角色|SocketCAN|标准帧 ID|实测 SN|
|---|---|---|---|
|right|can0|0x27|LHO6-04-276-R-Z-1-D|
|left|can1|0x28|LHO6-04-322-L-Z-1-D|

调用方显式选侧。适配器先检查配置的角色、SN 侧别和 CAN 端点，再用 Linkerbot SDK 0.5.4 读取实际 SN。身份不匹配时关闭会话并报错。读取角度使用 500 ms 的 SDK 请求超时，校验六通道和反馈时间。SDK 失败时异常返回，调用方应视为本次无可用状态。

## 离线使用

```python
from brick_stacking.hardware.mock_devices import MockHand

state = MockHand(role="right", raw_u8=(0, 25, 50, 100, 200, 255)).read_hand_state()
assert state["source"] == "mock"
assert state["raw_u8"] == (0, 25, 50, 100, 200, 255)
```

## 现场只读使用

在 Linux 设备主机上使用已审计的 Linkerbot SDK，目标 CAN 口应已配置为 UP 和 1 Mbps。适配器不修改 CAN 或 SDK 配置。SDK 构造可能启动传感器轮询，打开会话后立即停止轮询，再执行显式只读查询。停止轮询和关闭会话是通信操作。适配器没有下发角度、速度、抓握或物理停止的入口。

```python
from brick_stacking.hardware.o6_hand import O6Binding, O6HandAdapter

binding = O6Binding.load("config/hand/o6_observed.json", role="right")
with O6HandAdapter.open(binding) as hand:
    state = hand.read_hand_state()
    assert state["hand_sn"] == binding.serial_number
    assert state["raw_u8"] is None
    print(state["percent"])
```

SDK 返回六通道百分比，原始字节未知。Mock 示例返回六通道原始值。两种字段均保留各自的单位，适配器不推算弧度或反算原始值。通道顺序是拇指弯曲、拇指侧摆、食指、中指、无名指、小指。状态中的 `mapping_version` 是读取到的 SDK 映射摘要，`device_stamp` 保持为空，`host_receive_stamp` 使用本机单调时钟。温度、故障和触觉有效位均为 false。

现场验收分别记录两侧的 run_id、角色、SN、CAN、SDK 版本、`binding.config_hash`、`mapping_version` 和样本时间，确认只读期间无动作副作用。仓库离线验证通过 Mock 和 SDK 替身覆盖，现场只读验收待测。
