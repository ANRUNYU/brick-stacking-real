## 每个路点必须带的字段

| 字段 | 含义 |
|------|------|
| `name` | `hover` / `contact` / `micro_lift` / 以后的 `place_hover` |
| `frame` | `urdf`（SDK 默认）。姿态为外旋 ZYX：`rz, ry, rx` |
| `pose` | `x,y,z` 米；`rx,ry,rz` 弧度 |
| `q_rad` | 7 个数，该位姿的关节种子。7 轴 IK 依赖种子 |
| `approach_axis` | 从上一姿态到本点、离线探针判定为可规划的方向 |
| `hand_event` | 到达并停稳后执行的 O6 预设 id |

只给 xyz、或换坐标系而不写种子，路径侧无法复现今天的可达性。

## 手动作挂在路点上

路径算法不决定手指百分比。本侧给出预设，协作者在对应路点留挂点：

| 路点 | 预设 | 指令（0–100） | 说明 |
|------|------|----------------|------|
| `hover` | `open` | `[100,100,100,100,100,100]` | T2 已发出；未做块上闭合验证 |
| `contact` | `soft_close` | `[50,90,55,55,55,55]` | 软闭草稿；**未**在块上验证 |

| 放置下降到位 | `open` | 同 `open` | 放置阶段再用 |

`sdk_all_closed` 不进入此包。
