# B个人开发计划：相机与视觉

负责人：B；阶段一10点，阶段二10点。默认配对审查见总体计划。

## 1. 代码与职责
归属：hardware/中的相机适配、vision/、verification/及相关模型和测试。

可独立开工：先头部相机录包和离线检测；第二阶段用人工摆放多层结构采样，不必等机械臂先搭出来。

边界：不发送机械臂/手动作，不维护另一套机械臂外参，不提交slot最终成功。

主要交接：C：RGB-D/内参/时间与标定；D：观测及复检证据。

## 2. 第1阶段任务

### B1-01 按SN接入头部相机与录制（1点）

- 输入：审计SN和相机SDK。
- 工作与交付：CameraAdapter、RecordedCamera、采集说明。
- 验收：普通服务用户可取流；SN不匹配拒绝；不依赖videoN/index。
- 依赖与替代路径：M0；修权限按团队批准实施。

### B1-02 RGB-D配准与质量门控（2点）

- 输入：真实或录制RGB-D、内参。
- 工作与交付：注册图像、K/D、尺度、时钟信息及拒绝标记。
- 验收：分辨率对应、无效深度过滤；不得把未配准图声明为已配准。
- 依赖与替代路径：可独立；无A/C实现依赖。

### B1-03 独立木块检测与相机位姿（3点）

- 输入：样本图、实测尺寸先验。
- 工作与交付：BlockObservation，颜色/位置/不确定度。
- 验收：独立验证集检查漏检、误检与物理误差；模糊情况返回UNKNOWN。
- 依赖与替代路径：录包先行；尺寸由现场实测提供。

### B1-04 抓起/放下后的视觉复检（2点）

- 输入：前后帧、被检查区域/预期目标。
- 工作与交付：VerificationEvidence及证据ID。
- 验收：区分可见失败、遮挡和无法判断；不独自提交任务成功。
- 依赖与替代路径：Mock/录包独立；M2观测链。

### B1-05 单块视觉闭环接入（2点）

- 输入：C坐标契约、D流程。
- 工作与交付：真实观测/复检接入和失败样本集。
- 验收：参加M3；定位失败与执行失败可区分。
- 依赖与替代路径：M2→M3。

## 3. 第2阶段任务

### B2-01 多块同色实例与追踪线索（3点）

- 输入：多块录包、单块检测器。
- 工作与交付：观测集合、association hints、遮挡状态。
- 验收：分不清紧贴实例时拒绝；颜色不作为唯一ID。
- 依赖与替代路径：M3；独立采集/离线开发。

### B2-02 多层结构与支撑观测（3点）

- 输入：人工搭建正确/错误结构样本。
- 工作与交付：层占用/错位/倾斜/可观测性证据。
- 验收：不把被挡底层当消失；检测错误与不确定性分别统计。
- 依赖与替代路径：人工摆放录包即可，不等待机械臂堆叠。

### B2-03 光照和反光稳健性（2点）

- 输入：固定训练/验证样本划分。
- 工作与交付：曝光profile、质量阈值及回归集。
- 验收：亮暗/色温/高光下报告识别和拒绝率；配置可追溯。
- 依赖与替代路径：与其他第二阶段任务独立。

### B2-04 整场视觉指标和失效修复（2点）

- 输入：M5/M6录包。
- 工作与交付：视觉误差、掉帧、深度有效率和失败分析。
- 验收：修复视觉问题；需要腕机时只接当前所选侧，不默认启用三机融合。
- 依赖与替代路径：M5→M6。

## 4. 提交与合并

每个任务独立小PR；引用任务ID和对应M点。先提交Mock/录包/只读能力，再在关联任务补真机验收证据。生产者负责样例和Mock，接收者负责调用适配。M2配对联调，M3阶段一验收，M4离线十块流程，M5多层实机，M6整体验收。详见[合并计划](../MERGE_PLAN.md)。

所有实际测量和动作记录source、设备、配置、校准版本及run_id；没有做过的验证明确标待测。点数偏差在合并点调整，不能隐瞒阻塞或以模拟成功宣称真机通过。
