# 首次真实槽位参考与对照帧采集顺序

当前已确认：操作者2026-11-10确认头相机相对基座自C35标定以来未移动；已有目标槽位，具体标记/测量待提供。见config/observed/first_placement_reference_intake_20261110.json。这不是C35独立误差验收通过或实际设备枚举结果。

## 1. 先确定真实参考

接收槽位标记、参考坐标系、位置、单位、点语义及误差；没有数值时先确认实际标记，再由只读相机参考采集建立可审查参考。不得将供料红块当前观测作为目标，不默认选择黑色十字。marker像素位置本身不是已知三维坐标。

期望模型中心与期望顶面中心分列，桌面法向明确。需要独立参考变换时沿用m_ruler_validation.py两级桥接要求；不使用候选J1位置猜轴向。

## 2. 绑定采集会话

现场只启动相机读数，先核对设备序列号/实际profile/光学帧、boot与camera epoch、有效曝光映射及源文件hash；记录安装连续性操作者声明。候选C35 hash可以证明使用了哪份文件，但approved/独立精度未通过的状态不能改写。历史帧不补入新epoch或时钟界。相机采集与其他成员预约唯一占用，不启动SDK臂/手实例、CAN或运动。

## 3. 建立目标关联

明确供料区唯一红块及目标区域的边界，记录一次对象/区域关联确认及对应sample_id、observation_id、原始图像索引、scene/profile/calibration版本。逻辑target_id不等于实体关联。出现多块、遮挡、桌面移动或换布局时重新核对，不沿用旧确认。

## 4. 对照帧

参考与绑定通过后，再安排人工将块放至目标和经测量的偏移位置，记录独立标签及误差。每个条件采集稳定序列，保留冷启动/失败帧、颜色/遮挡/空区等负例。具体偏移量和稳定窗口在采集前与V冻结，不抄合成测试数值。

静态人工摆放对照只能验证相应静态视觉功能，不能伪造机器人action_started/action_finished、released或持握/放置执行证据。真正post_place还需执行端提供动作完成/释放事实以及V的稳定窗口；静态帧不能直接证明真实抓放闭环完成。
