2. 单臂自主十块搭建：红4、黄3、蓝2、绿1的单块厚度四层阶梯结构，包含支撑依赖、结果验证和有界恢复。

暂不开展双臂协作、交接和并发控制。主臂尚待运动/可达性/手状态评估后选择；另一侧须处于已确认的安全状态。真实动作前仍需腕轴质量、标定、限位、碰撞模型和停止能力验收。
